# 4. 시연 시나리오

본 문서는 「미슐랭 0스타」 서비스의 시연을 위해  
시연 순서에 따른 **site 화면별 구성**, **실행 단계별 클릭 위치 및 동작 결과**를 상세히 기술한 문서이다.  
본 문서에 따라 시연을 진행하면 동일한 결과를 재현할 수 있다.

---

## 4-1. 메인 페이지 진입 및 레시피 탐색

### 화면
- URL: `/`
- 화면명: 메인 페이지 (레시피 도서관)

### 실행 절차
1. 브라우저에서 서비스 URL 접속
2. 메인 페이지 로딩 확인

### 화면 구성
- 상단: 카테고리 탭 (밥 / 반찬 / 면 / 디저트 등)
- 중앙: 레시피 카드 리스트
- 하단: 페이지네이션

### 실행
1. 화면 중앙의 레시피 카드 영역을 아래로 스크롤
2. 상단 카테고리 중 **[밥]** 버튼 클릭

### 실행 결과
- 선택한 카테고리에 해당하는 레시피 리스트만 필터링되어 출력됨

---

## 4-2. 레시피 연구소 이동

### 화면
- 메뉴 위치: 상단 네비게이션 바
- 버튼명: `레시피 연구소`

### 실행
1. 상단 네비게이션 바에서 **[레시피 연구소]** 클릭

### 실행 결과
- URL `/lab`
- 사용자 레시피 등록 목록 화면 표시
- 레시피 작성자 정보가 3D 아바타로 표시됨

---

## 4-3. 레시피 상세 페이지 진입

### 화면
- 화면명: 레시피 상세 페이지

### 실행
1. 레시피 리스트에서 **[꽈리고추 삼겹살볶음]** 카드 클릭

### 화면 구성
- 레시피 대표 이미지
- 조리 시간, 칼로리, 인분 정보
- 재료 목록
- 단계별 조리 방법

### 실행 결과
- 해당 레시피의 상세 정보 페이지로 이동

---

## 4-4. 요리 모드 실행

### 화면
- 버튼 위치: 레시피 상세 페이지 하단
- 버튼명: `요리 시작하기`

### 실행
1. **[요리 시작하기]** 버튼 클릭

### 실행 결과
- URL `/cook/{recipeId}`
- 요리 전용 화면(요리 모드)로 전환
- 첫 번째 조리 단계 자동 표시

---

## 4-5. 음성 제어(STT) 기반 조리 단계 이동

### 화면
- 화면 하단: 마이크 아이콘
- 화면 중앙: 현재 조리 단계

### 실행
1. 화면 하단의 **마이크 아이콘 클릭**
2. 음성 입력: `"다음"`

### 실행 결과
- 음성 → 텍스트 변환(STT)
- 다음 조리 단계로 자동 이동
- 해당 단계에 타이머가 존재할 경우 자동 시작

---

## 4-6. AI 요리 도우미 기능 실행

### 화면
- 버튼 위치: 요리 모드 우측 하단
- 버튼명: `AI 도우미`

### 실행
1. **[AI 도우미]** 버튼 클릭
2. 음성 입력 버튼 클릭
3. 음성 입력: `"다음 단계 핵심만 요약해줘"`

### 실행 결과
- 음성 입력 내용이 텍스트로 변환
- AI 챗봇이 현재 단계 기준 요약 답변 제공
- 화면에 텍스트 응답 출력

---

## 4-7. 조리 완료 처리

### 실행
1. 마지막 조리 단계에서 **[다음]** 버튼 클릭

### 실행 결과
- 요리 완료 화면 표시
- 요리 성공 메시지 출력
- 사용자 요리 기록 자동 저장

---

## 4-8. 나눔 기능(학하동 나눔) 진입

### 화면
- 메뉴 위치: 하단 네비게이션 바
- 버튼명: `학하동 나눔`

### 실행
1. 하단 메뉴에서 **[학하동 나눔]** 클릭

### 실행 결과
- URL `/share`
- 지도 기반 또는 리스트 기반 나눔 게시글 화면 출력

---

## 4-9. 나눔 게시글 등록

### 화면
- 버튼 위치: 우측 하단 플로팅 버튼
- 버튼명: `+`

### 실행
1. **[+]** 버튼 클릭
2. 미리 작성된 테스트 게시글 내용 확인
3. **[등록]** 버튼 클릭

### 실행 결과
- 나눔 게시글 등록 완료
- 게시글 리스트에 즉시 반영됨

---

## 4-10. 채팅 기능 실행

### 화면
- 메뉴 위치: 하단 네비게이션 바
- 버튼명: `채팅`

### 실행
1. **[채팅]** 버튼 클릭
2. 채팅 리스트에서 테스트 채팅방 클릭

### 실행 결과
- 실시간 채팅 화면 진입
- 메시지 송수신 가능

---

## 4-11. 마이페이지 확인

### 화면
- 메뉴 위치: 하단 네비게이션 바
- 버튼명: `마이페이지`

### 실행
1. **[마이페이지]** 클릭

### 실행 결과
- 요리 완료 기록 확인
- 나눔 활동 내역 확인
- 사용자 레벨 및 점수 표시

---

## 4-12. 시연 종료

### 종료 상태
- 전체 시연 흐름 완료
- 데이터 정상 저장 확인
